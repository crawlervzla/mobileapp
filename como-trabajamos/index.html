La base de cada proyecto

Para qué sirve cada pieza de un proyecto.

Son las herramientas con las que se desarrolla el proyecto de un cliente. Cada una cumple una función: guardar los datos, responder las solicitudes, escribir el sistema, publicarlo o conservar el historial.

PostgreSQL · Los datos del proyecto

Guarda la información y define quién puede usarla.

PostgreSQL es el motor de base de datos del proyecto. Ahí queda la información del negocio: clientes, pedidos, usuarios o lo que la operación necesite. Organiza esos datos y confirma cada operación completa. Si el proceso se interrumpe, la información queda como estaba antes de esa operación. También define quién puede ver o modificar cada parte, incluso registro por registro. Si hace falta, la información se puede recuperar hasta un momento anterior.

Fuente: postgresql.org

Node.js · El servidor del proyecto

Recibe cada solicitud y devuelve una respuesta.

Node.js es el entorno donde corre el servidor del proyecto. Cuando alguien inicia sesión, envía un formulario o consulta un dato, esa petición llega aquí, se procesa y recibe una respuesta. Está hecho para atender muchas solicitudes al mismo tiempo, con poca espera.

Fuente: nodejs.org

TypeScript · Cómo se escribe el proyecto

Marca un dato incorrecto antes de que alguien use el sistema.

TypeScript es el lenguaje con el que se escribe el proyecto. Parte de JavaScript y agrega reglas sobre qué dato corresponde en cada parte. Si una función espera un número y recibe un texto, el error aparece al construir el sistema, antes de que una persona lo encuentre al usarlo. El resultado funciona en el navegador y en el servidor.

Fuente: typescriptlang.org

Vite · Cómo se publica la aplicación

Deja la aplicación lista para abrir en el navegador.

Vite prepara la parte web del proyecto para publicarla. Arma los archivos que la persona abre en el teléfono o en el computador, optimizados para los navegadores de uso habitual. Sirve para el sitio, el panel o la herramienta que el proyecto incluye.

Fuente: vite.dev

GitHub · El historial del proyecto

Conserva el proyecto y cada cambio que se le hace.

GitHub guarda los archivos del proyecto y el historial de cada modificación. Cualquier persona del equipo puede consultarlo desde otro equipo: se ve qué cambió y se puede volver a una versión anterior. Quienes construyen el proyecto trabajan sobre esa misma copia, y cada aporte queda registrado.

Fuente: docs.github.com

Inteligencia artificial · Una función del proyecto

Cumple una tarea concreta cuando el proyecto la necesita.

En un proyecto, la inteligencia artificial cumple una función definida: clasificar, redactar, resumir o responder, según lo que el negocio pida. El proveedor se informa en cada caso, junto con qué datos recibe. Las decisiones del negocio siguen en manos de las personas.
